# Contributing

Contributions are welcome when they keep the project focused on reproducible
Gemma 4 inference and operational clarity.

## Before opening a pull request

1. Open an issue for large behavioral changes.
2. Keep commits focused and describe user-visible intent.
3. Run `bash scripts/test_unit.sh`.
4. Update English and Vietnamese documentation when public behavior changes.
5. Never commit API keys, notebook tokens, model credentials or private URLs.

TPU-specific performance or compatibility claims should include reproducible
runtime details and evidence.
